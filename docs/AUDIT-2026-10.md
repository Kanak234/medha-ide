## D) KNOWN LAUNCH BUG (from history)

> **Last known bug:** `python3 -m medha` exited immediately with code 0, only printing `"QProcess::start: Process is already running"`, and no window appeared.

**Suspected causes to investigate in STEP 2-3:**
1. `QT_QPA_PLATFORM=xcb` forced unconditionally on Wayland — may cause issues if xcb not available
2. `QProcess` started twice (e.g., in `terminal.py` `start_shell()` called multiple times)
3. Exception swallowed during window initialization (e.g., import error in one of the 30+ modules)
4. Event loop never reached due to early `sys.exit()` or exception
5. `psutil` import failure on some systems
6. Missing `DISPLAY`/`WAYLAND_DISPLAY` causing platform plugin issues
