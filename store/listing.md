# Microsoft Store listing — MEDHĀ IDE

**Prepared version:** 2.0.0 (draft; not published)

**Name:** MEDHĀ IDE
**Category:** Developer tools (secondary: Education)
**Short description (≤100):** Offline C, C++, Java & Python IDE with Turbo C graphics.h, debugger and error help.

**Description:**
MEDHĀ is a free, offline IDE made for students. Write C, C++, Java and Python and press Ctrl+F5 — the compilers come inside the app (64-bit GCC, JDK 25, Python), no setup needed.
Old college Turbo C / Turbo C++ programs (graphics.h, conio.h, iostream.h, void main) run unchanged in a 640×480 screen, and "Modernize this code" shows how the same program looks in today's C11 / C++17 — with the reason for every change.
When something goes wrong, MEDHĀ explains the compiler error or crash in simple English or Hinglish and jumps to the line.

**Features**
- Built-in compilers: GCC/G++ (64-bit), Java 25, Python — works offline
- Turbo C mode: graphics.h + conio.h programs on Windows and Linux, 32 ready lab programs
- Beginner error and crash explanations (English / Hinglish)
- Debugger (GDB, debugpy), autocomplete, Git, CMake
- Offline security scan (CWE) and DSA / memory visualizers
