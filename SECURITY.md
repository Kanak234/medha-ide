# Security Policy

## Supported Versions

The following versions of MEDHĀ IDE are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in MEDHĀ IDE, please report it through responsible disclosure:

1. **GitHub Security Advisory (Preferred):** Submit a report via GitHub's [Private Vulnerability Reporting](https://github.com/Kanak234/medha-ide/security/advisories/new).
2. **Email:** Report security issues directly to the maintainer.

Please include:
- A clear description of the vulnerability and affected component.
- Reproduction steps or proof of concept.
- Expected vs. actual behavior and potential security impact.

### Response Timeframe
- **Initial Acknowledgement:** Within 48 hours.
- **Status & Triage:** Within 5 business days.
- **Patch & Disclosure:** Coordinated release schedule.

Please avoid public disclosure until a patch has been finalized and released.
